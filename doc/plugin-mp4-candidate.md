# 插件适配侧 MP4 交付

核对日期：2026-10-11。共同 MP4 行为以 [本地优先资料库规格](../spec/local-first-library.md)为主；本页记录托管适配侧的实现、验证与线上读回。

## 候选能力

- 网页和 MCP 分块上传都可接收 MP4 原件；服务端校验扩展名、MIME、字节数、SHA-256 和 `ftyp` 容器签名，再沿用现有附件记录与对象存储保存。
- 网页详情提供原生播放控件，支持字节范围定位和完整原件下载；不会自动播放、转写或建立视频索引。
- 浏览器若未报告 MIME 类型，服务端按 `.mp4` 扩展名识别后仍须通过 MP4 容器签名校验。

## 验证结果

- 插件适配侧隔离自动化测试 98/98 通过，含网页上传与读回、MCP 参数和分块导入、错误文件拒绝、跨用户隔离、HTTP Range 与完整下载。
- TypeScript 检查和生产构建通过。MP4 上传代码与相应用例的 ESLint 检查通过；全仓 ESLint 仍报 39 个错误和 1867 个警告，`app/atlas.tsx` 中的 8 个错误在本候选改动前已存在。
- Ego Lite 在本机临时身份代理和空 D1/R2 下完成网页路径：保存并读回 18,235 字节自制 MP4；播放器前进至 1.08 秒，时间轴键盘定位返回开头，Range 请求返回 206，下载文件与原件 SHA-256 相同。测试身份代理仅监听 `127.0.0.1` 并只转发到本地预览。
- 507-review 独立只读审查通过，修复了独立版空／通用 MIME 识别边界后未发现新的阻塞问题。
- 独立版已另行通过真实本地网页上传及视频播放／定位／下载验收；此证据不能代表插件适配版真实入口。
