# 卡片浏览的本地实现与验证

核对日期：2026-10-14。基线为 `aff1744`，本轮增加卡片浏览并保留关系画布。结果为独立版工作树中的本地实现；正式 0.0.4 标签、Release、远端与插件适配版未改变。

## 依据与实现

GitHub issue #1 请求保留直接阅读标题和摘要的选择。`v0.0.2` 的节点直接显示卡片，`fa56143` 与 `57c509f` 将主入口改为关系画布；当前预览仍有完整的卡片展示能力。本轮复用当前展示与操作规则，不恢复旧版卡片坐标系统。

行为主线见 [卡片浏览规格](../spec/local-first-library.md#浏览方式与卡片浏览)，词义与共用体验分别沿 GLOSSARY、DESIGN。

- `web/app/inspiration-card.tsx` 共用封面、原标题、可读摘要、标签与附件数量。关系预览只保留浮层位置、关闭与详情入口。
- `web/app/card-browser.tsx` 将当前记录集合按新建时间倒序排列，每批显示 50 条，接近底部自动追加；观察以卡片滚动容器为边界，隐藏或范围变化时取消旧观察。同页保留滚动与已显示批次，范围变化时回到结果顶部。图片延迟读取，不新建正文、摘要字段或资料缓存权威。
- `web/app/atlas.tsx` 持有共同资料及筛选，画布选择与详情标识分别维护。隐藏模式不接收画布滚轮、尺寸观察或临时适配；同一筛选及视口的模式往返不重新适配画布。浏览模式为页面状态，重新打开默认关系画布，持久画布视野仍由原资料库读取。
- 关系说明位于共用内容容器，在当前模式打开和返回；详情的「定位到画布」才显式切回。两种模式共用编辑、原件、冲突及保存流程，服务端、数据库格式、MCP、CLI、访问保护均未改变。

## 无限滚动修订与复验

507 认可原卡片浏览方案后，明确要求将「继续显示」改为无限滚动。本轮沿同一未提交工作树，只改变分批触发方式及末尾呈现，并同步现行 spec、DESIGN、README、CHANGELOG。服务端、资料字段、排序和位置规则保持。

卡片容器接近末尾时由浏览器的交叉观察自动追加 50 条，提前 320 像素触发；每次观察只追加一批，范围或模式改变时取消旧观察。没有新增网络分页请求；当前结果已经由共同资料入口读回，继续展示不产生写入。去掉点击入口，部分数量只保留给辅助技术，视觉上只在读完当前结果后显示「已显示全部」。内容不足视口时自动继续补足。

本轮重新创建隔离资料库，含 180 条自编记录，其中 168 条活跃、12 条归档；使用生产构建和同一 Ego Browser 页面，不操作私人资料库。网页复验结果：

## 发现与修正

- 首轮独立只读审查发现 P2：卡片详情查看关系说明会切回画布且不能返回原卡片。已将面板提升到共用容器，并按当前模式返回焦点；实际原路径已复验通过，包括详情关闭动画后的面板焦点。
- 最终审查发现另一项 P2：新建后的最终刷新较慢时，编辑器先卸载，`openDetail` 会用 body 覆盖新增按钮。已在发起项记录、详情打开及返回中排除 body；1500 ms 延迟原路径由 BODY 复验为 BUTTON／「新建灵感」。随后类型、生产构建和 60/60 测试再次通过。
- 首轮浏览器发现已有成功提示遮挡「继续显示」。当时已为底部操作预留空间并复验；无限滚动修订后取消该按钮，仍保留末尾提示的阅读空间。
- 验收脚本的早期滚动读数尚未稳定、筛选视野观察复用了旧缓存，不能作为位置恢复失败或放行依据。已以当前页面的完成状态与新基线复验，位置仍使用精确比较，没有放宽断言。部分可见大卡片的执行器自动点击中心被标题区遮挡，改为核对实际可见命中区域后点击；不是修改产品命中断言。

首轮独立只读审查已完成。两项 P2 均已关闭，当时范围未发现阻塞问题；审查者完整读取工程日志、实际验收回执及截图，并核对 16 个变更文件在各冻结审查前后指纹一致。首轮最后复核限定于三处 body 焦点保护及 1500 ms 延迟回执，其余有效结论保留。无限滚动修订另行独立复核，不沿用旧结论给新行为放行。本地通过不代表人工接受、共同版本交付或任何发布动作。
