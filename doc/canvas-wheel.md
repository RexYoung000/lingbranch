# 画布滚轮缩放修正

2026-10-11，507 确认无限画布的普通滚轮应围绕鼠标指针缩放。共同要求原位维护在 [画布合同](../spec/local-first-library.md#画布连线与归档)，体验在 [DESIGN](../DESIGN.md)；本修正先作为0.0.3后的增量完成，随后按507要求纳入0.0.4；定版与渠道状态见 [0.0.4记录](release-0.0.4.md)，原0.0.3标签保持。

## 原因与实现

旧处理只在 Ctrl／Meta 修饰键下缩放，普通滚轮将 deltaX／deltaY 写成平移。修改前实际网页复现：向上滚轮后缩放保持 100%，纵向平移增加，未达到用户要求。

两版画布统一通过各自 atlas-view 的 wheelCanvasView 计算视野：统一像素、行、页单位，向上放大、向下缩小，以当前指针的世界坐标反算新平移；缩放边界及无纵向输入保持原视野。连续事件立即更新当前视野引用，避免同一批输入复用旧值。保留非被动监听以阻止画布原生滚动，放行聚合依据、关系面板和窄屏结果列表；门户中的详情、编辑器继续自身滚动。

沿已有视野保存入口写入，不改节点、内容、附件、关系或数据结构。空白拖拽、缩放按钮、持久视野与临时筛选的规则保持。画布操作说明增加滚轮缩放与空白拖拽。

## 验证与边界

- 独立版 npm run check 通过：类型、生产构建及 55 项测试；插件版 npm test 的 84 项、类型与生产构建通过。未新增依赖或迁移。
- 每版新增 5 项回归：偏移视口与平移下的指针锚定、双向恢复、三种滚轮单位、极小／最大缩放边界、横向／零输入，以及连续改变指针的事件。
- 两版隔离网页实际滚轮双向缩放通过，指针锚定的屏幕误差小于 0.004 像素；纯横向滚轮保持视野。空白拖拽、详情长正文滚动、聚合依据不缩放画布、视野保存后刷新恢复、筛选缩放不覆盖原视野均通过；样例节点的所有字段与连接保持。
- 边界测试在极小缩放下比较实际屏幕位置，避免用放大的世界坐标误差误判浮点精度。网页验证使用实际鼠标事件的整数坐标，并等待详情入场完成；保留首次失败记录，没有改生产规则来迎合测试。
- 插件本地样例预览原缺已有的关系说明迁移。备份后只在本地应用既有迁移，再完成关系样例验证；没有向线上注入身份或资料。
- 真机触控板捏合、其他浏览器与触摸设备未单独验收；普通纵向滚轮与单位计算已验证，不据此承诺所有设备。

本地修正与网页路径已通过，独立只读审查无阻塞，Standards／Spec／Code Quality均通过，19文件冻结一致，两版窄回归独立复跑10／10通过。原插件站点第19版已部署成功，MCP就绪；线上在临时筛选视野实际双向滚轮通过，指针锚定测量误差小于0.01屏幕像素。退出筛选后完整资料、节点坐标、附件元数据、连接及持久视野快照相同，原站／插件身份和完整访问策略保持。线上没有测试资料写入或重排。本次公开定版与发行状态由 [0.0.4记录](release-0.0.4.md)维护，原0.0.3发行保持。交付当前快照见 [PROGRESS](../PROGRESS.md)。
