# Sites 私有资料库

本规格扩展 [本机路径](local-first-library.md)，保留原画布体验与本机模式。Sites 部署使用一份 D1 资料库与 R2 附件存储，手机、电脑网页和已连接的 Site 插件共用同一份资料。初次打开为空库，不导入任何真实灵感或维护者实例数据。

关系画布／卡片浏览沿用共用规格：共享搜索、标签、归档及详情；卡片直接显示标题、封面与摘要，并自动继续展示。两种视图分别保留同页浏览位置，浏览及切换不改写节点坐标或形成第二份资料；本次适配不增加数据库字段或迁移。

## 访问与连接

- Site 仅部署者本人可访问，由 Sites 平台管理 ChatGPT 登录与远程 MCP OAuth。不得改为公开或放宽访问来完成验证。
- 所有资料读取、附件、导出与修改在服务器端要求可信的 `oai-authenticated-user-id`。客户端自报身份、普通 Bearer 令牌或仅有服务访问凭据不代替用户身份。
- 浏览器登录通过平台 `/signin-with-chatgpt` 顶层导航；不接收独立访问令牌，不创建新 OAuth 或大模型账号配置。
- `/mcp` 是无状态 Streamable HTTP MCP，支持初始化、15 个工具的发现与调用。发现只含公共接口说明；任何工具调用需要已认证用户。原 `/api/tools` 仍为 JSON 接口，不冒充 MCP。
- 只有用户安装或连接 Sites 提供的插件并完成实际调用后，才可以声称聊天客户端已经接通。

## 持久化与一致性

- 网页 HTTP API 与 MCP 使用同一 D1 操作模块，保留标题、正文、来源、标签、坐标、归档、无向连线、画布视野和版本冲突规则。
- 可重试写入保留稳定请求标识及参数指纹；重复调用返回既有结果，异参数复用返回冲突。D1 原子批处理同时提交变更与凭据，使用资料库版本检查避免并发卡片占用同一位置。
- 读取采用数据库快照或明确的分页上界。刷新和重新启动不产生另一份资料库；浏览器缓存仅为视图。
- D1 表结构由随源码提交的 Drizzle 迁移管理，不在请求处理中建立或修改表。已发布的迁移保持原样；升级仅追加正文格式与关系说明字段，原正文按 plain 保留，旧连接保留标识、两端并默认关联类型与空理由。
- 网页与 HTTP MCP 沿用上游 Markdown 正文、附件引用、关系类型和理由、整批布局操作及版本冲突合同。正文图片必须属于当前记录；整批布局在所有版本检查通过后原子写入，并保留原位置。
- 保存回执重试不重建已移除的连接，不用历史关系说明覆盖后来修改；布局回执与原位置备份继续可读。
- MP4 继承上游容器签名、原件下载和范围播放合同；未经支持的媒体编码保留下载入口。
- R2 先写完整原件并校验，再提交 D1 元数据；失败可遗留未引用原件，但不能出现引用未完成原件的成功记录。20 MiB 上限、SHA-256、类型签名、UTF-8 校验和分段读取继续适用。
- 云端导出保留可由本机恢复命令读入的版本 3 资料包、原件、关系、布局与重试凭据，使用分段编码和压缩避免在 Worker 中一次保存整个资料包。解压后资料包继续限制为 128 MiB，超过限制明确失败，不丢弃附件后报告成功。第一版不提供云端恢复或跨实例导入，本机隔离恢复继续保留。

## 验收

1. 未认证的资料、工具调用、附件和导出被拒绝；跨站写入被拒绝，发现不包含私有数据。
2. 在空库保存两条示例灵感，检索、修改、建立并移除连线，重复请求不重复记录，过期版本更新失败。
3. 在 HTTP MCP 更新后由网页 API 读回一致结果，重启 Worker 后仍保留记录、连线、附件与视野。
4. 上传原件、读回并检查大小与 SHA-256，导出可由原本机隔离恢复入口验证。
5. 官方私有发布达到成功终态，并核实 owner-only 访问配置。源码 fork 和 Site 数据、身份、凭据分开，真实资料与凭据不进入公共 Git。

具体执行结果、客户端连接边界及未覆盖范围见工程验证说明，不以构建或接口发现代替实际验证。
